Step 0

Notation and Conventions

  • \(Q, K \in \mathbb{R}^{L\times D_k}\), \(V, O \in \mathbb{R}^{L\times D_v}\), \(S, P \in \mathbb{R}^{L\times L}\), scalar loss \(\mathcal{L}\).
  • \(\mathbf{s}_i^\top,\ \mathbf{p}_i^\top,\ \mathbf{o}_i^\top\) denote the \(i\)-th rows of \(S, P, O\) (so \(\mathbf{s}_i, \mathbf{p}_i \in \mathbb{R}^{L}\) are column vectors).
  • \(\mathbf{1}\): all-ones vector. \(\odot\): elementwise (Hadamard) product. \(\exp(\cdot)\): elementwise.
  • \(\mathrm{diag}(\mathbf{x})\): diagonal matrix built from vector \(\mathbf{x}\).
  • Adjoint (gradient) of \(X\): \(\bar{X} = \partial\mathcal{L}/\partial X\), same shape as \(X\), defined by \[ d\mathcal{L} = \langle \bar{X}, dX\rangle_F = \mathrm{Tr}\big(\bar{X}^\top dX\big). \]
  • Components \(Q_{ik}, K_{jk}, V_{jd}, O_{id}, S_{ij}, P_{ij}\); scalar loss \(\mathcal{L}\).
  • Sequence indices \(i, j, m, n \in [1, L]\); feature index \(k \in [1, D_k]\); value index \(d \in [1, D_v]\).
  • Summation convention: an index repeated within a term is summed, \(A_k B_k \equiv \sum_k A_k B_k\).
  • Free indices: an index that appears on the left-hand side is free on the right-hand side and is not summed.
  • Kronecker delta \(\delta_{jm} = 1\) if \(j=m\), else \(0\).
  • Adjoint of \(X\): \(\bar{X}_{ab} = \partial\mathcal{L}/\partial X_{ab}\), defined by \[ d\mathcal{L} = \bar{X}_{ab}\, dX_{ab}. \]

The row normalizer is written \(\ell_i\) here (it is \(L_i\) in the PDF) to avoid a clash with the sequence length \(L\).

Step 1

Forward Pass

\[ S = \tfrac{1}{\sqrt{D_k}}\, Q K^\top,\quad \boldsymbol{\ell} = \exp(S)\,\mathbf{1},\quad P = \mathrm{diag}(\boldsymbol{\ell})^{-1}\exp(S),\quad O = P V \]
Operationsmatrix product, transpose, elementwise exp, diagonal scaling
\[ S_{ij} = \tfrac{1}{\sqrt{D_k}}\, Q_{ik} K_{jk},\quad \ell_i = \textstyle\sum_n \exp(S_{in}),\quad P_{ij} = \dfrac{\exp(S_{ij})}{\ell_i},\quad O_{id} = P_{ij} V_{jd} \]
Operationsindex contraction
Detailed derivation (4 steps)
1.1 · Scaled scores
\[ S = \frac{1}{\sqrt{D_k}}\, Q K^\top \in \mathbb{R}^{L\times L} \]
\[ S_{ij} = \frac{1}{\sqrt{D_k}} \sum_{k=1}^{D_k} Q_{ik} K_{jk} = \frac{1}{\sqrt{D_k}}\, Q_{ik} K_{jk} \]
1.2 · Row normalizer (partition function)
\[ \boldsymbol{\ell} = \exp(S)\,\mathbf{1} \in \mathbb{R}^{L} \]
\[ \ell_i = \sum_{n=1}^{L} \exp(S_{in}) \]
1.3 · Row-wise softmax
\[ P = \mathrm{diag}(\boldsymbol{\ell})^{-1} \exp(S), \qquad \mathbf{p}_i = \frac{\exp(\mathbf{s}_i)}{\ell_i}, \qquad P\,\mathbf{1} = \mathbf{1} \]
\[ P_{ij} = \frac{\exp(S_{ij})}{\ell_i}, \qquad \sum_{j=1}^{L} P_{ij} = 1 \]
1.4 · Output
\[ O = P V \in \mathbb{R}^{L\times D_v} \]
\[ O_{id} = \sum_{j=1}^{L} P_{ij} V_{jd} = P_{ij} V_{jd} \]
Step 2

Output Variation: Gradients of \(V\) and \(P\)

\[ \boxed{\bar{V} = P^\top \bar{O}} \qquad \boxed{\bar{P} = \bar{O}\, V^\top} \]
Operationsproduct rule, trace cyclicity, transpose identities
\[ \boxed{\bar{V}_{jd} = P_{ij}\, \bar{O}_{id}} \qquad \boxed{\bar{P}_{im} = \bar{O}_{id}\, V_{md}} \]
Operationsproduct rule, reordering scalar factors, renaming a dummy index
Detailed derivation (5 steps)
2.1 · Loss differential at the output
\[ d\mathcal{L} = \mathrm{Tr}\big(\bar{O}^\top dO\big) \]
\[ d\mathcal{L} = \bar{O}_{id}\, dO_{id} \]
2.2 · Product rule on the output
\[ dO = d(PV) = dP\, V + P\, dV \]
\[ dO_{id} = d(P_{im} V_{md}) = dP_{im}\, V_{md} + P_{im}\, dV_{md} \]
2.3 · Substitute
\[ d\mathcal{L} = \mathrm{Tr}\big(\bar{O}^\top dP\, V\big) + \mathrm{Tr}\big(\bar{O}^\top P\, dV\big) \]
\[ d\mathcal{L} = \bar{O}_{id}\, dP_{im}\, V_{md} + \bar{O}_{id}\, P_{im}\, dV_{md} \]
2.4 · Bring each term to the canonical form “coefficient × differential”
Using \(\mathrm{Tr}(ABC) = \mathrm{Tr}(CAB)\): \[ \mathrm{Tr}\big(\bar{O}^\top dP\, V\big) = \mathrm{Tr}\big(V \bar{O}^\top dP\big) = \mathrm{Tr}\big((\bar{O} V^\top)^\top dP\big) \] \[ \mathrm{Tr}\big(\bar{O}^\top P\, dV\big) = \mathrm{Tr}\big((P^\top \bar{O})^\top dV\big) \]
Each term is a product of scalars, so the factors can be reordered freely: \[ d\mathcal{L} = \big(\bar{O}_{id} V_{md}\big)\, dP_{im} + \big(P_{im} \bar{O}_{id}\big)\, dV_{md} \]
2.5 · Identify the adjoints
Match with \(d\mathcal{L} = \mathrm{Tr}(\bar{P}^\top dP) + \mathrm{Tr}(\bar{V}^\top dV)\): \[ \bar{P} = \bar{O}\, V^\top, \qquad \bar{V} = P^\top \bar{O} \]
Match with \(d\mathcal{L} = \bar{P}_{im}\, dP_{im} + \bar{V}_{md}\, dV_{md}\), then rename \(m \to j\): \[ \bar{P}_{im} = \bar{O}_{id} V_{md}, \qquad \bar{V}_{jd} = P_{ij}\, \bar{O}_{id} \]
Step 3

Softmax Jacobian

\[ \boxed{J_i = \frac{\partial \mathbf{p}_i}{\partial \mathbf{s}_i} = \mathrm{diag}(\mathbf{p}_i) - \mathbf{p}_i \mathbf{p}_i^\top} \quad \text{(one } L\times L \text{ Jacobian per row } i\text{)} \]
Operationsrow slicing, vector quotient rule, diagonal matrix, outer product
\[ \boxed{\frac{\partial P_{im}}{\partial S_{ij}} = P_{im}\big(\delta_{jm} - P_{ij}\big)} \]
Operationsscalar quotient rule, Kronecker delta, sifting property
Detailed derivation (5 steps)
3.1 · Set up the quotient
Softmax acts on each row separately; take row \(i\): \[ \mathbf{p}_i = \frac{\mathbf{u}}{v}, \qquad \mathbf{u} = \exp(\mathbf{s}_i) \in \mathbb{R}^{L}, \qquad v = \mathbf{1}^\top \exp(\mathbf{s}_i) = \ell_i \]
\[ P_{im} = \frac{u}{v}, \qquad u = \exp(S_{im}), \qquad v = \ell_i = \sum_{n} \exp(S_{in}) \]
3.2 · Quotient rule
\[ J_i = \frac{1}{v}\,\frac{\partial \mathbf{u}}{\partial \mathbf{s}_i} - \frac{1}{v^2}\, \mathbf{u}\, \frac{\partial v}{\partial \mathbf{s}_i} \] \(\partial\mathbf{u}/\partial\mathbf{s}_i\) is \(L\times L\); \(\partial v/\partial\mathbf{s}_i\) is a \(1\times L\) row vector.
\[ \frac{\partial P_{im}}{\partial S_{ij}} = \frac{\dfrac{\partial u}{\partial S_{ij}}\, v - u\, \dfrac{\partial v}{\partial S_{ij}}}{v^2} \]
3.3 · Derivative of the numerator
An elementwise map has a diagonal Jacobian: \[ \frac{\partial \mathbf{u}}{\partial \mathbf{s}_i} = \mathrm{diag}\big(\exp(\mathbf{s}_i)\big) \]
Apply the chain rule to \(u = \exp(S_{im})\): \[ \frac{\partial u}{\partial S_{ij}} = \exp(S_{im})\,\frac{\partial S_{im}}{\partial S_{ij}} \] Because \(S_{i1}, \dots, S_{iL}\) are independent coordinates in row \(i\), there are two cases:
  • If \(j = m\): \(S_{im}\) and \(S_{ij}\) are the same variable, so \(\dfrac{\partial S_{im}}{\partial S_{ij}} = 1 \;\Rightarrow\; \dfrac{\partial u}{\partial S_{ij}} = \exp(S_{im})\).
  • If \(j \neq m\): \(S_{im}\) does not depend on \(S_{ij}\), so \(\dfrac{\partial S_{im}}{\partial S_{ij}} = 0 \;\Rightarrow\; \dfrac{\partial u}{\partial S_{ij}} = 0\).
Combining both cases via the Kronecker delta \(\delta_{jm} = \begin{cases} 1, & j=m \\ 0, & j\neq m \end{cases}\): \[ \frac{\partial S_{im}}{\partial S_{ij}} = \delta_{jm} \quad\Longrightarrow\quad \frac{\partial u}{\partial S_{ij}} = \exp(S_{im})\, \delta_{jm} \]
3.4 · Derivative of the denominator
\[ \frac{\partial v}{\partial \mathbf{s}_i} = \mathbf{1}^\top \mathrm{diag}\big(\exp(\mathbf{s}_i)\big) = \exp(\mathbf{s}_i)^\top \]
\[ \frac{\partial v}{\partial S_{ij}} = \sum_{n} \exp(S_{in})\, \delta_{jn} = \exp(S_{ij}) \] Sifting: only the \(n = j\) term survives.
3.5 · Assemble and substitute the forward definition
\[ J_i = \frac{\mathrm{diag}\big(\exp(\mathbf{s}_i)\big)}{\ell_i} - \frac{\exp(\mathbf{s}_i)\,\exp(\mathbf{s}_i)^\top}{\ell_i^2} \] \[ = \mathrm{diag}(\mathbf{p}_i) - \mathbf{p}_i \mathbf{p}_i^\top \] Note that \(J_i\) is symmetric.
\[ \frac{\partial P_{im}}{\partial S_{ij}} = \frac{\delta_{jm}\exp(S_{im})\,\ell_i - \exp(S_{im})\exp(S_{ij})}{\ell_i^2} \] \[ = \delta_{jm} P_{im} - P_{im} P_{ij} = P_{im}\big(\delta_{jm} - P_{ij}\big) \]
Step 4

Backpropagating Through Softmax: Gradient of \(S\)

\[ \boxed{\bar{S} = P \odot \big(\bar{P} - D\,\mathbf{1}^\top\big)}, \qquad \boxed{D = (P \odot \bar{P})\,\mathbf{1}} \in \mathbb{R}^{L} \]
Operationsrow-wise decomposition, symmetry of \(J_i\), Hadamard product, broadcasting via \(D\mathbf{1}^\top\)
\[ \boxed{\bar{S}_{ij} = P_{ij}\big(\bar{P}_{ij} - D_i\big)}, \qquad \boxed{D_i = P_{im}\, \bar{P}_{im}} \]
Operationschain rule, Kronecker sifting, factoring
Detailed derivation (5 steps)
4.1 · Separate the two branches
\[ d\mathcal{L} = \mathrm{Tr}\big(\bar{P}^\top dP\big) + \mathrm{Tr}\big(\bar{V}^\top dV\big) \] \(V\) is an independent input (\(V = XW_V\)), so the \(dV\) term does not depend on \(S\). Only the first term carries \(dS\).
\[ d\mathcal{L} = \bar{P}_{im}\, dP_{im} + \bar{V}_{jd}\, dV_{jd} \] \(\partial V_{jd}/\partial S_{ij} = 0\), so only the first term carries \(dS\).
4.2 · Chain rule through softmax
Split the Frobenius pairing into rows and use \(d\mathbf{p}_i = J_i\, d\mathbf{s}_i\): \[ \mathrm{Tr}\big(\bar{P}^\top dP\big) = \sum_i \bar{\mathbf{p}}_i^\top d\mathbf{p}_i = \sum_i \bar{\mathbf{p}}_i^\top J_i\, d\mathbf{s}_i \]
Use \(dP_{im} = \dfrac{\partial P_{im}}{\partial S_{ij}}\, dS_{ij}\): \[ \bar{P}_{im}\, dP_{im} = \bar{P}_{im}\, \frac{\partial P_{im}}{\partial S_{ij}}\, dS_{ij} \]
4.3 · Identify the adjoint of \(S\)
\[ \bar{\mathbf{s}}_i = J_i^\top \bar{\mathbf{p}}_i = J_i\, \bar{\mathbf{p}}_i \qquad (J_i \text{ symmetric}) \]
\[ \bar{S}_{ij} = \bar{P}_{im}\, \frac{\partial P_{im}}{\partial S_{ij}} \]
4.4 · Substitute the Jacobian
\[ \bar{\mathbf{s}}_i = \mathrm{diag}(\mathbf{p}_i)\,\bar{\mathbf{p}}_i - \mathbf{p}_i\,\big(\mathbf{p}_i^\top \bar{\mathbf{p}}_i\big) = \mathbf{p}_i \odot \bar{\mathbf{p}}_i - D_i\, \mathbf{p}_i \] with \(D_i := \mathbf{p}_i^\top \bar{\mathbf{p}}_i\) (a scalar).
\[ \bar{S}_{ij} = \bar{P}_{im} P_{im}\, \delta_{jm} - \bar{P}_{im} P_{im}\, P_{ij} = P_{ij}\, \bar{P}_{ij} - P_{ij}\, D_i \] with \(D_i := P_{im}\bar{P}_{im}\) (summed over \(m\)); the \(\delta_{jm}\) term keeps only \(m = j\).
4.5 · Factor and assemble
\[ \bar{\mathbf{s}}_i = \mathbf{p}_i \odot \big(\bar{\mathbf{p}}_i - D_i\, \mathbf{1}\big) \] Stacking the rows: \[ D = (P \odot \bar{P})\,\mathbf{1}, \qquad \bar{S} = P \odot \big(\bar{P} - D\,\mathbf{1}^\top\big) \]
\[ \bar{S}_{ij} = P_{ij}\big(\bar{P}_{ij} - D_i\big), \qquad D_i = P_{im}\,\bar{P}_{im} \] This already holds for all \(i, j\); no stacking step is needed.
Step 5

Eliminating \(\bar{P}\) from \(D\)

\[ \boxed{D = (P \odot \bar{P})\,\mathbf{1} = (O \odot \bar{O})\,\mathbf{1}} \]
Operationsrow extraction, associativity of matrix products, identity \((A\odot B)\mathbf{1} = \mathrm{diag}(AB^\top)\)
\[ \boxed{D_i = P_{im}\,\bar{P}_{im} = O_{id}\,\bar{O}_{id}} \]
Operationssubstitution, reordering a finite double sum

Why it matters: the left form of \(D\) uses \(\bar{P} \in \mathbb{R}^{L\times L}\); the right form uses only \(O, \bar{O} \in \mathbb{R}^{L\times D_v}\), which are already available. Cost drops from \(\mathcal{O}(L^2)\) storage to an \(\mathcal{O}(L D_v)\) row-wise dot product.

Detailed derivation (5 steps)
5.1 · Starting point
\[ D_i = \mathbf{p}_i^\top \bar{\mathbf{p}}_i \qquad \big(D = (P\odot\bar{P})\,\mathbf{1}\big) \]
\[ D_i = P_{im}\, \bar{P}_{im} \]
5.2 · Substitute the gradient of \(P\) from Step 2
Row \(i\) of \(\bar{P} = \bar{O}V^\top\) is \(\bar{\mathbf{p}}_i^\top = \bar{\mathbf{o}}_i^\top V^\top\), i.e. \(\bar{\mathbf{p}}_i = V \bar{\mathbf{o}}_i\): \[ D_i = \mathbf{p}_i^\top \big(V\, \bar{\mathbf{o}}_i\big) \]
Use \(\bar{P}_{im} = \bar{O}_{id} V_{md}\): \[ D_i = P_{im}\, \big(\bar{O}_{id}\, V_{md}\big) = \sum_{m}\sum_{d} P_{im}\, \bar{O}_{id}\, V_{md} \]
5.3 · Regroup
Associativity of the matrix product: \[ D_i = \big(\mathbf{p}_i^\top V\big)\, \bar{\mathbf{o}}_i \]
Swap the order of the two finite sums (sum over \(m\) first): \[ D_i = \sum_{d} \Big(\sum_{m} P_{im} V_{md}\Big) \bar{O}_{id} = \big(P_{im} V_{md}\big)\, \bar{O}_{id} \]
5.4 · Recognize the forward output
Row \(i\) of \(O = PV\) is \(\mathbf{o}_i^\top = \mathbf{p}_i^\top V\): \[ D_i = \mathbf{o}_i^\top \bar{\mathbf{o}}_i \]
\(P_{im} V_{md} = O_{id}\) by Step 1.4: \[ D_i = O_{id}\, \bar{O}_{id} \]
5.5 · Statement for all rows at once
Here \(\mathrm{diag}(\cdot)\) extracts the diagonal of a matrix. With \((A\odot B)\mathbf{1} = \mathrm{diag}(AB^\top)\) and \(\bar{P}^\top = V\bar{O}^\top\): \[ D = \mathrm{diag}\big(P\bar{P}^\top\big) = \mathrm{diag}\big(PV\bar{O}^\top\big) = \mathrm{diag}\big(O\bar{O}^\top\big) = (O\odot\bar{O})\,\mathbf{1} \]
\(i\) is a free index, so 5.4 already holds for every row: \[ D_i = O_{id}\, \bar{O}_{id} \quad \forall\, i \]
Step 6

Gradients of \(Q\) and \(K\)

\[ \boxed{\bar{Q} = \tfrac{1}{\sqrt{D_k}}\, \bar{S} K} \qquad \boxed{\bar{K} = \tfrac{1}{\sqrt{D_k}}\, \bar{S}^\top Q} \]
Operationsproduct rule, trace cyclicity, \(\mathrm{Tr}(A) = \mathrm{Tr}(A^\top)\)
\[ \boxed{\bar{Q}_{ik} = \tfrac{1}{\sqrt{D_k}}\, \bar{S}_{ij} K_{jk}} \qquad \boxed{\bar{K}_{jk} = \tfrac{1}{\sqrt{D_k}}\, \bar{S}_{ij} Q_{ik}} \]
Operationsproduct rule, reading off coefficients
Detailed derivation (4 steps)
6.1 · Differential of the scores
\[ dS = \frac{1}{\sqrt{D_k}}\Big(dQ\, K^\top + Q\, dK^\top\Big) \]
\[ dS_{ij} = \frac{1}{\sqrt{D_k}}\Big(dQ_{ik}\, K_{jk} + Q_{ik}\, dK_{jk}\Big) \]
6.2 · Substitute into \(d\mathcal{L}\)
\[ d\mathcal{L} = \mathrm{Tr}\big(\bar{S}^\top dS\big) = \frac{1}{\sqrt{D_k}}\Big[\mathrm{Tr}\big(\bar{S}^\top dQ\, K^\top\big) + \mathrm{Tr}\big(\bar{S}^\top Q\, dK^\top\big)\Big] \]
\[ d\mathcal{L} = \bar{S}_{ij}\, dS_{ij} = \frac{1}{\sqrt{D_k}}\Big[\bar{S}_{ij} K_{jk}\, dQ_{ik} + \bar{S}_{ij} Q_{ik}\, dK_{jk}\Big] \]
6.3 · Canonical form
\[ \mathrm{Tr}\big(\bar{S}^\top dQ\, K^\top\big) = \mathrm{Tr}\big(K^\top \bar{S}^\top dQ\big) = \mathrm{Tr}\big((\bar{S}K)^\top dQ\big) \] \[ \mathrm{Tr}\big(\bar{S}^\top Q\, dK^\top\big) = \mathrm{Tr}\big(dK\, Q^\top \bar{S}\big) = \mathrm{Tr}\big((\bar{S}^\top Q)^\top dK\big) \]
Already in canonical form: the coefficient of \(dQ_{ik}\) is \(\bar{S}_{ij}K_{jk}\) (summed over \(j\)), and the coefficient of \(dK_{jk}\) is \(\bar{S}_{ij}Q_{ik}\) (summed over \(i\)).
6.4 · Identify
\[ \bar{Q} = \frac{1}{\sqrt{D_k}}\, \bar{S} K, \qquad \bar{K} = \frac{1}{\sqrt{D_k}}\, \bar{S}^\top Q \]
\[ \bar{Q}_{ik} = \frac{1}{\sqrt{D_k}}\, \bar{S}_{ij} K_{jk}, \qquad \bar{K}_{jk} = \frac{1}{\sqrt{D_k}}\, \bar{S}_{ij} Q_{ik} \]
Step 7

From Equations to the Tiled Backward Kernel

The kernel processes blocks of query rows \(I\) and key rows \(J\) in on-chip SRAM. Inside a tile, \(\bar{S}_{IJ} = P_{IJ}\odot(\bar{P}_{IJ} - D_I\mathbf{1}^\top)\) requires \(D_I\).

By its original definition \(D = (P\odot\bar{P})\mathbf{1}\), \(D_I\) depends on every key block. Step 5 gives \(D = (O\odot\bar{O})\mathbf{1}\), which can be computed before the loop.

The kernel processes blocks of query indices \(i\in I\) and key indices \(j\in J\) in on-chip SRAM. Inside a tile, \(\bar{S}_{ij} = P_{ij}(\bar{P}_{ij} - D_i)\) requires \(D_i\).

By its original definition \(D_i = P_{im}\bar{P}_{im}\), \(D_i\) sums over all \(m\in[1,L]\). Step 5 gives \(D_i = O_{id}\bar{O}_{id}\), which can be computed before the loop.

Kernel outline in both notations
7.1 · Precompute (once, \(\mathcal{O}(L D_v)\))
D = rowsum(O ⊙ Ō)                 # shape (L,)
D_i = O_id Ō_id                   # for all i
7.2 · For each tile (query block I, key block J), in SRAM
S_IJ  = Q_I K_J^T / √D_k
P_IJ  = exp(S_IJ) / ℓ_I            # ℓ saved from forward
P̄_IJ  = Ō_I V_J^T
S̄_IJ  = P_IJ ⊙ (P̄_IJ − D_I 1^T)

V̄_J  += P_IJ^T Ō_I
Q̄_I  += S̄_IJ K_J   / √D_k
K̄_J  += S̄_IJ^T Q_I / √D_k
S_ij  = Q_ik K_jk / √D_k
P_ij  = exp(S_ij) / ℓ_i            # ℓ saved from forward
P̄_ij  = Ō_id V_jd
S̄_ij  = P_ij (P̄_ij − D_i)

V̄_jd += P_ij Ō_id                  # partial sum over i ∈ I
Q̄_ik += S̄_ij K_jk / √D_k           # partial sum over j ∈ J
K̄_jk += S̄_ij Q_ik / √D_k           # partial sum over i ∈ I
7.3 · Memory footprint
\(P_{IJ}, \bar{P}_{IJ}, \bar{S}_{IJ}\) live only in SRAM/registers for the current tile. Global memory holds \(Q, K, V, O, \bar{O}\), the vectors \(\boldsymbol{\ell}, D \in \mathbb{R}^L\), and the outputs \(\bar{Q}, \bar{K}, \bar{V}\).
The \(L\times L\) arrays \(P, \bar{P}, \bar{S}\) are never written to global memory. Extra storage beyond inputs and outputs: \(\ell_i\) and \(D_i\), i.e. \(\mathcal{O}(L)\).

8.3 · Transient tensors computed on the fly SRAM only
