Sparse Attention Backward Pass: Rows vs. Columns

Why the gradient of \(Q\) is computed row by row and the gradients of \(K, V\) column by column, and how this is read directly from the free and summed indices. Uses only the indices \(i, j, k, d\) from the FlashAttention derivation plus a binary mask \(M_{ij}\).

Step 1

The Mask and the Forward Pass

Matrix calculus

Mask \(M \in \{0,1\}^{L\times L}\): query \(i\) may attend to key \(j\) iff \(M_{ij}=1\).

\[ S = \tfrac{1}{\sqrt{D_k}}\,QK^\top,\qquad P = \mathrm{diag}(\boldsymbol{\ell})^{-1}\big(M \odot \exp(S)\big),\qquad O = PV \] \[ \boldsymbol{\ell} = \big(M\odot\exp(S)\big)\mathbf{1} \]

Einstein notation tensor calculus

Mask \(M_{ij}\in\{0,1\}\): query \(i\) may attend to key \(j\) iff \(M_{ij}=1\).

\[ S_{ij} = \tfrac{1}{\sqrt{D_k}}\,Q_{ik}K_{jk},\qquad P_{ij} = \frac{M_{ij}\exp(S_{ij})}{\ell_i},\qquad O_{id} = P_{ij}V_{jd} \] \[ \ell_i = \textstyle\sum_{n} M_{in}\exp(S_{in}) \]

Running example (\(L=6\)): every token attends to the first token (an attention sink) and to a local window of itself and the previous token. Then \(M_{ij}=0 \Rightarrow P_{ij}=0\).

Step 2

Backward Equations

\[ \bar{S} = P\odot(\bar{P} - D\mathbf{1}^\top),\qquad D = (O\odot\bar{O})\mathbf{1} \] \[ \bar{Q} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}K,\qquad \bar{K} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}^\top Q,\qquad \bar{V} = P^\top\bar{O} \]
\[ \bar{S}_{ij} = P_{ij}(\bar{P}_{ij} - D_i),\qquad D_i = O_{id}\bar{O}_{id} \] \[ \bar{Q}_{ik} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}_{ij}K_{jk},\qquad \bar{K}_{jk} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}_{ij}Q_{ik},\qquad \bar{V}_{jd} = P_{ij}\bar{O}_{id} \]

These are the dense FlashAttention equations. The mask enters only through \(P_{ij}\), and since \(\bar{S}_{ij}\) carries the factor \(P_{ij}\), it has the same zero pattern as \(M_{ij}\).

Detailed derivation with the mask
2.1 · Masked softmax Jacobian
\[ J_i = \mathrm{diag}(\mathbf{p}_i) - \mathbf{p}_i\mathbf{p}_i^\top, \] where \(\mathbf{p}_i\) is row \(i\) of \(P\), already zero wherever \(M_{ij}=0\).
With \(\partial \ell_i/\partial S_{ij} = M_{ij}\exp(S_{ij})\) and \(\partial M_{im}/\partial S_{ij}=0\): \[ \frac{\partial P_{im}}{\partial S_{ij}} = \frac{\delta_{jm}M_{im}e^{S_{im}}\,\ell_i - M_{im}e^{S_{im}}\,M_{ij}e^{S_{ij}}}{\ell_i^2} = P_{im}(\delta_{jm} - P_{ij}) \]
2.2 · Gradient of the scores
\[ \bar{\mathbf{s}}_i = J_i\,\bar{\mathbf{p}}_i = \mathbf{p}_i\odot\bar{\mathbf{p}}_i - (\mathbf{p}_i^\top\bar{\mathbf{p}}_i)\,\mathbf{p}_i \] \[ \bar{S} = P\odot(\bar{P} - D\mathbf{1}^\top) \]
\[ \bar{S}_{ij} = \bar{P}_{im}\,P_{im}(\delta_{jm} - P_{ij}) = P_{ij}\bar{P}_{ij} - P_{ij}\,P_{im}\bar{P}_{im} = P_{ij}(\bar{P}_{ij} - D_i) \]
2.3 · Row reduction is unaffected by the mask
\[ D = (P\odot\bar{P})\mathbf{1} = (P\odot\bar{O}V^\top)\mathbf{1} = (O\odot\bar{O})\mathbf{1} \]
\[ D_i = P_{im}\bar{P}_{im} = P_{im}\,\bar{O}_{id}V_{md} = (P_{im}V_{md})\,\bar{O}_{id} = O_{id}\bar{O}_{id} \]
2.4 · Zero pattern
\(\bar{S}\) has the same zero pattern as \(P\), hence as \(M\).
\(M_{ij}=0 \;\Rightarrow\; P_{ij}=0 \;\Rightarrow\; \bar{S}_{ij}=0.\)
Step 3

Reading the Loop Structure from the Indices

\[ \bar{Q} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}K \qquad\text{vs.}\qquad \bar{K} = \tfrac{1}{\sqrt{D_k}}\,\bar{S}^\top Q \]

The two products differ by a transpose of the same sparse matrix \(\bar{S}\). Which way the sparse matrix has to be traversed for each product is not part of the expression.

\[ \bar{Q}_{ik} = \frac{1}{\sqrt{D_k}}\sum_{j\,:\,M_{ij}=1}\bar{S}_{ij}K_{jk} \qquad\text{vs.}\qquad \bar{K}_{jk} = \frac{1}{\sqrt{D_k}}\sum_{i\,:\,M_{ij}=1}\bar{S}_{ij}Q_{ik} \]

\(\bar{Q}_{ik}\): free \(i\), summed \(j\), so fix row \(i\) and sweep across it.
\(\bar{K}_{jk}\): free \(j\), summed \(i\), so fix column \(j\) and sweep down it.

Free index = which output a thread block owns (one block per value of the free index).
Summed index = which direction it sweeps across the mask, visiting only entries with \(M_{ij}=1\).

Step 5

Two Storage Formats for the Same Mask

CSR (row-major list)

Answers: for query \(i\), which keys are active? Row \(i\) is the slice col_idx[row_ptr[i-1] : row_ptr[i]].

Used by every equation whose free index is \(i\): \(O_{id} = P_{ij}V_{jd}\) and \(\bar{Q}_{ik} = \tfrac{1}{\sqrt{D_k}}\bar{S}_{ij}K_{jk}\).

CSC (column-major list)

Answers: for key \(j\), which queries attend to it? Column \(j\) is the slice row_idx[col_ptr[j-1] : col_ptr[j]].

Used by every equation whose free index is \(j\): \(\bar{K}_{jk} = \tfrac{1}{\sqrt{D_k}}\bar{S}_{ij}Q_{ik}\) and \(\bar{V}_{jd} = P_{ij}\bar{O}_{id}\).

Both lists describe the same 15 nonzeros. Building CSC from CSR is a one-time transpose of the index pattern (a counting sort over \(j\)). For a static mask it is done once and reused across layers, heads and steps.

Step 6

From Tokens to Tiles

Real kernels apply the same logic to \(B_r\times B_c\) tiles: replace \(M\) by a block mask over query blocks \(I\) and key blocks \(J\). A tile is skipped when its block of \(M\) is all zero.

The forward and \(\bar{Q}\) loops iterate over the active key blocks \(J\) of each query block \(I\) (CSR). The \(\bar{K}, \bar{V}\) loop iterates over the active query blocks \(I\) of each key block \(J\) (CSC).

A single fused backward kernel has to pick one traversal. FlashAttention-2 sweeps columns, so it owns \(\bar{K}_J, \bar{V}_J\) and accumulates \(\bar{Q}\) with atomic adds. Splash Attention provides separate \(\bar{Q}\) and \(\bar{K},\bar{V}\) backward kernels, so each output is written by its owner.
